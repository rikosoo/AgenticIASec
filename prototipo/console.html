O que esta tela é e não é

  • É um protótipo do console. Os prompts listados representam eventos já capturados e enviados por usuários, vindos de coletores (hook do Claude Code, extensão, inference hooks). Aqui eles são simulados.
  • Não é o motor de produção. O detector roda em JavaScript no navegador (CPF/CNPJ com dígito verificador, cartão com Luhn, chaves AWS, tokens GitHub, JWT, chave privada, e-mail, telefone, shell perigoso, heurísticas de injection). O motor real (Python, Presidio, classificador) está previsto para a Etapa 2.
  • Usuários e e-mails são fictícios (domínio de exemplo). Nenhum dado real.
  • Nenhuma captura real acontece aqui. A coleta exige os coletores e a API (Etapas 3 a 5 e 8). A ferramenta "Simular um prompt" apenas testa as regras.
  • Limites de cobertura (ver docs/viabilidade.md): contas pessoais só pela extensão; inference hooks só Claude Enterprise e só o lado do prompt; resposta do modelo fora do alcance inline.
  • O texto exibido já vem mascarado. O original não é guardado. O indicador de risco exige revisão humana.
  • Dados ficam só neste navegador (armazenamento local, se permitido).
