O que esta tela é e não é

  • É um protótipo do console com detector heurístico em JavaScript (CPF/CNPJ com dígito verificador, cartão com Luhn, chaves AWS, tokens GitHub, JWT, chaves privadas, e-mail, telefone, comandos shell perigosos, heurísticas de injection).
  • Não é o motor de produção. O motor real (Python, Presidio, classificador) está previsto para a Etapa 2 e não foi construído.
  • Não coleta nada sozinho. Só analisa o texto que você cola aqui. Nada sai do navegador. Os incidentes ficam apenas nesta aba (e no armazenamento local, se permitido).
  • Dados de exemplo estão rotulados como simulados. Use apenas dados sintéticos.
  • Mascaramento: o texto exibido já vem mascarado; o original não é guardado.
  • Para usar com o Claude Code de verdade falta a API (Etapa 3) e o adaptador de hook (Etapa 4). Esta interface é o console da Etapa 6, com dados locais no lugar da API.
  • Classificação das integrações: ver docs/viabilidade.md (nenhuma está testada ainda).
